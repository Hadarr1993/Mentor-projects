# גיליון גוגל — המטבח של קאמפ פרדייז

סקריפט אחד שבונה את כל חוברת העבודה בגוגל שיטס: לשוניות, נוסחאות, צבעים,
רשימות נפתחות, תיבות סימון ודאשבורד.

## התקנה

1. פתח [sheets.new](https://sheets.new)
2. `תוספים` → `Apps Script`
3. מחק את מה שיש שם, הדבק את כל `CampKitchen.gs`, שמור
4. בחר את הפונקציה `buildKitchenSheet` ולחץ ▶ (בפעם הראשונה גוגל יבקש הרשאה)

אחרי ההרצה הראשונה יופיע בשורת התפריטים תפריט **קאמפ פרדייז** שממנו אפשר
לבנות הכל מחדש, בלי לחזור ל-Apps Script.

> הרצה חוזרת **מוחקת ובונה מחדש**. מה שמילאתם ביד יימחק — הורידו עותק לפני.

## הלשוניות

| לשונית | מה יש בה |
|---|---|
| דאשבורד | עלות, תקציב, התקדמות קניות ומשימות, בדיקות שפיות |
| הגדרות | סועדים, ימים, רזרבה, תאריך, תקציב, צוות — חדר הבקרה |
| תפריט השבוע | 12 ארוחות, בחירת מנה ותוספות מרשימה, שיבוץ תורנים |
| מתכונים / תוספות | כמויות **לאדם אחד**, שורה לכל מצרך |
| הוראות הכנה | שלבי הבישול, מיועד להדפסה ולתלייה במטבח |
| בוקר ומזווה | כמות לאדם ליום |
| פריטים נוספים | מה שלא מגיע ממתכון — קבוע / לפי אדם / לפי אדם ליום |
| קניות | נבנית לבד מכל המקורות לעיל |
| משימות | אחראי, תיבת סימון, דחיפות |

## החישוב

זהה ללוגיקה של האפליקציה ב-`src/lib/calc.js`:

```
מצרך במתכון   כמות לאדם × כמה פעמים המנה בתפריט × סועדים × (1+רזרבה)
בוקר / מזווה   כמות לאדם × ימים × סועדים × (1+רזרבה)
פריט נוסף      קבוע | לפי אדם | לפי אדם ליום
```

אומת מול `calc.js` על 63 שורות מצרכים בתפריט מלא של 12 ארוחות — התאמה מדויקת.

## למה זה בנוי ככה

רשימת הקניות מרכיבה את עצמה מ-`UNIQUE` על כל מקורות המצרכים, ולא מרשימה
קבועה. מתכון חדש נכנס לקניות מיד, בלי לזכור להוסיף שורה — זה ההבדל בין
גיליון שמחזיק שנים לבין גיליון שנשבר בשקט.

עמודות מחושבות מוגנות באזהרה (לא בנעילה): אפשר להמשיך, אבל אי אפשר לדרוס
נוסחה בלי לשים לב.
